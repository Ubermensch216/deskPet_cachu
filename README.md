# 카츄 — 바탕화면을 걸어다니는 친구

`desk_gamcheoni`(감천이)와 같은 기능의 데스크톱 펫입니다. 캐릭터 그림은 `ref/source_sheet.png`(6포즈 시트)를 씁니다.
기능·조작·설정은 감천이와 동일합니다(클릭 반응, 던지기, 벽·천장·창 타기, 간식·친밀도, 알림, 도우미 창 등). 자세한 사용법은 `..\desk_gamcheoni\README.md` 참고.

## 실행
`output\카츄.exe` (설치 불필요, .NET Framework 4.8). 설정·기록은 `%AppData%\카츄\` 에 저장됩니다.

## 포즈 그림 → 애니메이션
시트의 체크무늬·별 배경은 그림에 박혀 있어서 `tools\extract-poses.ps1` 로 지우고 포즈별 PNG(`ref\pose1~6.png`)로 잘라 냅니다. (pose5 는 pose4 의 좌우 반전이라 쓰지 않음)

| 상태 | 그림 |
|---|---|
| 걷기·서기·모이기·벽·천장 | pose4 서기 — 입을 다문 **차분한 얼굴**(원본 입을 털색으로 덮고 ω 입을 그림) |
| 낙하·폴짝·기지개·하품·어질어질·들고 끌기 | pose4 원본 — 놀란(입 벌린) 얼굴 |
| 앉기·멍때리기·간식 먹기·슬라이딩 | pose1 엎드림 |
| 낮잠 | pose2 잠(눈 감은 그림 그대로, Z 세 개) |
| 우는 중·배고픔 | pose3 앉아 울기 + 눈물 |
| 클릭으로 눌림·세게 흔들림·던져짐·번개 방출 | pose6 발끈(전기 볼) |

코드로 만든 것: 눈 깜빡임(서기·엎드림은 고해상도 원본에서 눈을 감은 변형을 따로 그림), 프로펠러, 눈물, 돌아가는 소용돌이 눈, 고글, 꽃다발, Z, 생각 점, 음표, 쿠키. 눈·입 위치는 `src/Art.cs` 의 `PoseDef` 에 있습니다.
애니메이션 원칙은 감천이와 같습니다: 가로세로 비율은 바꾸지 않고 균일 확대와 발끝 기준 회전만 사용.

## 우산 낙하
내려올 때는 머리에 프로펠러를 다는 대신, **프로펠러 자루를 우산 손잡이처럼 한 손으로 쥐고** 매달립니다(자루 끝 프로펠러가 돌고, 자루 꼭대기를 축으로 대롱대롱 흔들림). 쥐는 손 위치는 `PoseDef.Grip`.

## 번개 방출
볼에 전기를 모으며 파르르 떨다가(0.75초) 사방으로 번개를 방출하고(1.4초, 몸이 번쩍이고 노란 빛무리) 잦아듭니다.
* 우클릭 → 동작 바로 보기 → 번개 방출
* 같은 친구를 2초 안에 4번 누르면 발끈해서 번개를 냅니다(‘숨겨진 반응 사용’ 켜진 경우, 친구 기록의 발견한 비밀에 기록)
* 가끔 혼자 쉴 때가 되면 가끔(약 12%) 스스로 번개를 냅니다(얌전 모드 제외)
